Microsoft 365 User Onboarding Toolkit
A PowerShell-based automation solution for onboarding Microsoft 365 users using Microsoft Graph.

Features
 * User Creation
 * License Assignment
 * Group Membership Management
 * User Reporting
 * Automated Onboarding Workflow
   
Technologies
 * PowerShell
 * Microsoft Graph
 * Microsoft Entra ID
 * Microsoft 365

   
Repository Structure
 Documentation/
 Scripts/
 README.md
 
Business Value
 - Reduces manual effort when onboarding new employees while ensuring consistent provisioning, licensing and reporting.
