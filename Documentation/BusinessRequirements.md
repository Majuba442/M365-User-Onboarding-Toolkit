Business Requirement

Background

Many organizations onboard users manually into Microsoft 365.

Common challenges include:
 * Incorrect license assignment
 * Missing group membership
 * Delayed onboarding
 * Human error
   
Goal
Create a PowerShell-based automation toolkit that:
 * Creates users
 * Assigns licenses
 * Adds group memberships
 * Generates reports
   
Technologies
 * Microsoft Graph
 * PowerShell
 * Microsoft Entra ID
 * Microsoft 365
